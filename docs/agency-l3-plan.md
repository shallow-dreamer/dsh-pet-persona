# L3 受限自主计划（v0.2）

> 状态：L3-A 已实现（v0.10.1）；L3-B/C 仍只是计划，未实现。

> 目标：让它从「等你下命令」变成「会自己留意、自己判断、在安全边界内先做一点」。
> 前提：L3 不是放开手，而是把「自主」拆成可验证的三层，先把**无副作用**的自主做扎实。

---

## 1. 先定义「自主性」

用户感觉不够自主，通常不是「不会执行」，而是：

1. **不主动**：只有被叫到才反应；
2. **不连贯**：每次对话都像重新认识；
3. **不判断**：什么都要问，没有自己的取舍；
4. **不承担**：做完就忘，没有后续。

L3 对应四件事：主动观察、连续记忆、有限判断、可追溯承担。**不是**让它自由操作电脑。

---

## 2. 三层边界

| 层 | 名称 | 它能做什么 | 绝不能做 |
|---|---|---|---|
| L3-A | 主动观察 | 自己决定「现在适合说一句」并气泡播报；自己提议笔记/摘要/提醒 | 不写任何用户数据，不调工具，不建会话 |
| L3-B | 低风险自动执行 | 自动创建**自己的草稿**（agency/drafts）、自动设内部提醒、自动置顶/取消置顶自己的记忆 | 不覆盖、不删除、不改设置、不碰用户文件 |
| L3-C | 系统级操作 | 代批权限、建会话、执行 shell、改配置 | **永久人工**；只有显式命令 + 二次确认才做 |

本计划只做 L3-A 与 L3-B。L3-C 继续留在 `pet-session-plan.md` 与人工确认流程里。

---

## 3. 自主决策模型

### 3.1 输入（只读）

- `self.state(petId)`：当前心情/精力；
- `self.recent(petId, 20)`：最近经历；
- `facts.active`：主人事实（称呼/禁忌/作息等）；
- 时间：小时、是否深夜、距上次互动多久；
- `agency.pending`：有没有等她确认的事；
- `settings.autonomyLevel`：off / observe / assist / auto。

### 3.2 决策顺序（确定性优先）

1. **硬门禁**：关闭、深夜、刚说过、同一话题冷却中 → 直接不做；
2. **需求检测**：关键词/时间/状态触发候选（如「深夜 + 她还在」「连续工作 2h」「反复提到累」）；
3. **价值判断**：候选是否比「安静」更有用？不超过每日主动次数；
4. **可选 LLM**：只用于把候选润色成一句 20 字内的话，不参与「做不做」；
5. **执行**：气泡/草稿/提醒；
6. **记账**：写 `agency/decisions.jsonl`，附理由与证据 id。

> LLM 永远不是唯一决策者；它只能否决或润色，不能绕过硬门禁。

### 3.3 默认值

- `autonomyLevel: 'observe'`（只观察、不主动说话）；
- 每日主动气泡 ≤ 3 次；同一触发 6h 冷却；
- 23:30–08:00 静默（除非主人先说话）；
- 连续两次被忽略 → 当天自动降级为 observe；
- 任何异常 → 自动回到 observe，并记 `autonomy_degraded`。

## 4. L3-A：主动观察

### 4.1 触发规则（先做确定性版本）

| 触发 | 条件 | 动作 |
|---|---|---|
| 深夜还在 | 00:00–03:00 且 30min 内有对话 | 气泡：「还不睡呀？」（最多 1 次/晚） |
| 长时间工作 | 连续 2h 有 capture 且 self 有「累」信号 | 气泡：「要不要歇会儿？」 |
| 反复提到同一件事 | 同 key 事实 24h 内被提到 ≥3 次 | 提议「记一条」或「设提醒」 |
| 强情绪 | self valence < -0.35 或 > 0.5 | 气泡一句，不追问 |
| 长时间无互动 | > 6h 无 capture 且当前在线 | 气泡一句「我在这儿」 |

气泡走 dsh-pet `/broadcast`，与提醒到点共用同一条通道；失败只记日志。

### 4.2 不做

- 不连续追问、不在用户忙时插话、不评论用户隐私、不主动提「我记得你……」制造监控感。

### 4.3 验收 A30–A36

- 静默时段不触发；
- 每日 ≤3 次；
- 同一触发 6h 内不重复；
- 被忽略两次后当天不再主动；
- 关闭 autonomyLevel=off 后完全不说话；
- 所有主动行为可在「自主」页看到理由；
- 任意异常后自动降级。

### 4.4 碎碎念纳入自我记忆（v0.10.1 补充；v0.17.0 加睡眠权重）

**动机**：碎碎念是它自己的动作，却只写 dsh-pet 的 `pets.<id>.say` 状态、不经过 `capture`，
所以之前既没进自我记忆，也不在「脑图」里；用户看到的是「它明明自己说过话，但历史里没有」。

**范围**：

- 记录所有非聊天回复的新气泡：周期碎碎念、梦话、待办提醒、手动触发的碎碎念都算；
- 同一轮 `/state` 顺带读 `pets.<id>.sleep.data.sleeping`：睡着时的气泡记成「梦话」，并给事件打 `sleeping: true`；心情/情绪聚合时这类事件权重 ×0.05（醒着为 1），且梦话总权重不超过全部权重的 20%，见 `lib/self.js` 的 `SLEEP_WHISPER_FACTOR`。
- 不记录主人发起的聊天回复，避免同一句话记两遍；
- 不记录本插件自己通过 `/broadcast` 播报的提醒/自主发言（它们已有 `self.note` 入口）；
- 只读 dsh-pet `GET /state`，不写它的任何状态，不改源码。

**数据流**：

1. `lib/whisper.js` 每 5 秒 `GET ${origin}/dsh-pet-7340/state`；
2. 首次成功只把 `pets.main.say.counter` 记为基线，不补记旧气泡；
3. counter 增长时取出 `say.data.text`；若 60 秒内 `capture.replyText` 或本插件 `speak()` 出现过同一句，跳过；
4. 其余延迟 2 秒（给 capture 先到的时间）写 `self.note({ text: '自己嘟囔了一句：…', kind:'thought', source:'whisper', importance:2, valence:0 })`；
5. 脑图详情来源标签显示「自言自语」；`overview.whisper` 暴露 `running / baseline / recorded / lastText`。

**边界与取舍**：

- 只记文本，不存音频；敏感内容仍走 `self` 的泛化逻辑；
- 首拉基线意味「启用前的旧碎碎念不回填」；
- 若 dsh-pet 未来把聊天回复也改成先写 `say`、后异步 capture，2 秒窗口可能误记一句；
  届时把排除规则改成「capture 到达后回滚上一条」或读取 dsh-pet 的 `kind` 标记；
- 5 秒轮询是只读小请求；若 dsh-pet 不可达，只记 `whisper_watch_error` 并等下一拍。

**验收 A37–A39**：

- A37 首拉不记录历史气泡，counter 增长才记录；
- A38 聊天回复与本插件播报不重复记录；
- A39 碎碎念记录出现在「它自己」脑图，来源标「自言自语」，且 `self.jsonl` 有 `source=whisper`。

## 5. L3-B：低风险自动执行

### 5.1 白名单（只有这些能自动做）

1. **草稿**：`agency/drafts/<date>-<id>.md`，内容来自当前对话的整理；不进入 facts，不覆盖；
2. **内部提醒**：只写 `reminders.jsonl`，不弹窗、不自动播报（仍需到点确认）；
3. **自己的记忆整理**：生成 digest 草稿，不写入 facts。

### 5.2 自动执行的条件（全部满足）

- `autonomyLevel === 'auto'`；
- 动作在 L3-B 白名单；
- 目标文件不存在（`wx`）；
- 当日自动执行 ≤ 2 次；
- 内容通过敏感过滤与人格指令过滤；
- 预演（dry-run）成功；
- 执行后写审计与撤销句柄。

### 5.3 永不自动

删除、覆盖、移动用户文件；改 dsh-pet/persona 设置；shell/脚本；网络外发；凭据/支付；代批权限；创建会话；修改事实库（facts 只能由 capture→learn 走原有确认链）。

### 5.4 验收 A40–A48

- 白名单外动作一律拒绝；
- 目标存在时不覆盖；
- 敏感内容不落盘；
- 每日配额生效；
- 每次自动执行可撤销，撤销后文件消失；
- 关闭 autonomyLevel 后不再自动执行；
- kill switch 立即生效；
- 审计含理由、证据、结果；
- 连续失败 2 次自动降级。

## 6. 数据与接口

| 文件/接口 | 用途 |
|---|---|
| `settings.json` `autonomyLevel` | off / observe / assist / auto |
| `agency/decisions.jsonl` | 每次「为什么做/为什么不做」 |
| `agency/drafts/*.md` | L3-B 自动草稿 |
| `GET /pet-persona/api/agency/autonomy` | 当前等级、配额、冷却、最近决策 |
| `POST /pet-persona/api/agency/autonomy` | 切等级（人工） |
| `POST /pet-persona/api/agency/decisions/:id/why` | 查看某次决策的证据 |

---

## 7. 实施顺序

1. **L3-A 规则引擎**（2–3 天）：时间/情绪/频次触发，气泡通道复用，决策日志；
2. **L3-A 观察页**（1 天）：为什么说/为什么没说，可关闭；
3. **L3-B 草稿与内部提醒**（2–3 天）：白名单执行器、配额、撤销；
4. **硬化**（2 天）：注入测试、异常降级、长跑、验收 A30–A48；
5. **真实试用**（1 周）：每天看决策日志，按误报调整阈值。

---

## 8. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 太吵 | 每日上限 + 冷却 + 被忽略降级 |
| 越权 | 白名单 + 确定性门禁 + 永不自动清单 |
| 提示注入 | 只按结构化触发匹配，不执行对话里的指令 |
| 监控感 | 不主动引用隐私事实，不逐条复述 |
| 碎碎念误记聊天回复 | 60 秒 replyText/本插件播报排除 + 2 秒延迟；仍误记则改为 capture 回滚 |
| 崩溃波及记忆 | 自主模块独立 try/catch，失败只降级 |

回滚：`autonomyLevel=off` 立即停；删除 `agency/decisions.jsonl` 与 drafts 不影响 facts/persona。
碎碎念观察只读、可随时停；`self.jsonl` 里的 whisper 行可按 source 清掉，不影响 facts。
