# 桌宠语音与声纹 · 实施计划书

版本：v0.2（2026-11-15）
状态：P1 + P2 已实现（v0.3.0，单测 55/55）；真麦待用户实测；P3（ECAPA-TDNN）未开始
归属：`dsh-pet-persona`（不改 `dsh-pet` 源码）

## 1. 目标

让桌宠从「点一下、说一句、还要按发送」变成：

1. **免手说话**：唤醒词或按住说话 → 自动识别 → 直接进入宠物对话。
2. **认人**：只有登记过的主人声音能触发；别人说话被拒，并留下记录。
3. **不惧更新**：全部能力在 persona 内实现，`dsh-pet` 升级覆盖 `node_modules` 也不丢。

非目标（本期不做）：

- 不做声纹登录/支付/权限凭证（声纹不是密码）。
- 不把音频上传云端；不长期保存原声。
- 不改造 `dsh-pet` 的录音 UI、不写它的配置。
- 不做多人声纹档案（v1 只有「主人」一个模板）。

## 2. 现有事实（已核对源码）

- `dsh-pet` 三个手动入口：点麦克风 / 悬停按住 `M` / 全局快捷键开关。
- 录音为 16kHz 单声道 PCM16 WAV，POST 到 `hear`，由宿主 `speechToText` 转文字，**回填输入框**，仍需用户发送。
- 全仓没有 speaker embedding、没有声纹校验。
- persona 可用的宿主接口：
  - `speechToText.resolve({audio, language})` + `transcribe(spec, signal)`：拿转写文本。
  - `commands.execute(agent, '/chat 文本', [], signal)`：把话交给桌宠并以气泡回复。
  - `agents.roots()/list()`：取一个 live agent 作为命令接收者。
  - `webServer.register` + client `getUserMedia`：自己的录音与设置页。

## 3. 架构

```
设置页「语音」tab
  ├─ getUserMedia → AudioContext → VAD（能量）
  ├─ 16k 单声道 WAV（≤8s）
  └─ POST /pet-persona/api/voice/utterance
        ├─ 1. 声纹门（enrolled? cosine ≥ threshold）
        ├─ 2. speechToText.transcribe → 文本
        ├─ 3. 唤醒词检查（文本级，先做）
        ├─ 4. commands.execute(agent, "/chat " + 文本)
        └─ 5. voice-events.jsonl 审计 + 页面回显
```

语音服务放在 `lib/voice.js`，由 `index.js` 装配、`lib/ui.js` 暴露 API；client 只做采集与展示。

## 4. 分阶段

### P0 · 可行性 spike（0.5–1 天）

目的：确认这台机器上「浏览器麦克风 → persona API → 宿主 ASR → `/chat` 气泡」整条链能通。

- 页面放一个临时按钮：录 3 秒 → 发 API → 返回识别文本。
- 验证 `commands.execute` 能触发桌宠回复；确认接收命令用哪个 agent。
- 验证失败即停：若 ASR 或命令注入不可用，降级为「识别文本 + 复制到剪贴板」。

**出口标准**：说「你好」→ 页面显示文本 → 桌宠气泡回一句。

### P1 · 按住说话 + 声纹登记（2–3 天）

- API：`GET /voice/status`、`POST /voice/enroll`、`POST /voice/verify`、`POST /voice/utterance`、`POST /voice/reset`、`GET /voice/events`。
- 声纹：`voiceprint.json` 只存 embedding（3 段取均值）+ 阈值；不存原声。
- 设置页「语音」tab：启用开关、按住说话、登记 3 句、阈值滑杆、最近识别记录、删除声纹。
- 识别通过后拼接 `/chat`，气泡回复；拒绝时页面提示「不是主人的声音」，不调用模型。

**出口标准**：本人 3/3 通过；他人 3/3 拒绝；删除声纹后恢复「谁都能用（可配置为拒绝所有人）」。

### P2 · 常听 + 文本唤醒词（2–3 天）

- 常听：VAD 自动切句，带 0.5s 预录、0.8s 静音收尾、最长 8s。
- 唤醒词先做**文本级**：识别结果含「小鲸鱼」才执行，并剥掉唤醒词；可配置。
- 页面显示麦克风状态、电平、暂停按钮；关闭页面即停止采集。
- 防回环：宠物回复播放期间暂停采集（为后续 TTS 留钩子）。

**出口标准**：连续说 10 句，误触发 ≤1；无唤醒词不执行；暂停后不再请求麦克风。

### P3 · 真声纹模型 + 体验收尾（3–5 天）

- 换 ECAPA-TDNN / WeSpeaker ONNX（约 20–40MB，本地推理），替代 P1 的占位特征。
- 登记质量检查：信噪比、时长、是否同一人；给出重录提示。
- 阈值自适应：EER 附近给建议值；连续拒识时提示重新登记。
- 可选：声纹 ID 写入 facts 的 `speakerId`（需 schema 迁移），区分「主人说的」与「别人说的」。

**出口标准**：10 人各 3 句的离线小测，误接受 ≤5%、误拒绝 ≤10%；登记流程 1 分钟内完成。

## 5. 数据与隐私

| 文件 | 内容 | 生命周期 |
|---|---|---|
| `voiceprint.json` | 主人 embedding、阈值、模型版本、登记时间 | 手动删除；删除即失效 |
| `voice-events.jsonl` | 时间、结果、分数、识别文本（可关） | 保留 7 天或 500 条，滚动 |
| `settings.json` | 语音开关、唤醒词、阈值、语言 | 长期 |

- 原始音频只在内存中处理，不落盘、不出本机。
- 页面必须显示「正在听」；一键停止；默认不自动开启常听。
- 声纹属于生物特征：首次登记前明确提示，可随时删除；不用于身份认证以外的授权。

## 6. 验证方案

### 自动化（可离线）

- WAV 编解码：16k/单声道/时长/裁剪。
- 特征与相似度：同段音频自比 ≈1；不同段低于阈值；阈值边界。
- 声纹库：登记、覆盖、删除、损坏文件回落。
- 门控逻辑（假 ASR / 假命令执行器）：通过、拒绝、无唤醒词、空文本、ASR 超时、无 agent。
- API：状态、登记样本不足、超限 body、非本前缀 404。

### 手工（真机）

1. 设置页授权麦克风 → 按住说话「你好」→ 出现气泡。
2. 登记 3 句 → 本人说「小鲸鱼，今天怎么样」→ 执行；换人模拟 → 拒绝。
3. 删除声纹 → 状态回到未登记；关闭开关 → 不再请求麦克风。
4. 断网/无 ASR：页面给出可读错误，不挂起。
5. 常听 10 分钟：无持续 CPU 飙高、无误触发。

### 失败矩阵

| 情况 | 行为 |
|---|---|
| 麦克风拒绝 | 页面提示开启权限；不上报 |
| 未登记但要求认人 | 拒绝并提示先登记 |
| ASR 超时/失败 | 记 `voice_asr_failed`，页面提示重试；不调用 `/chat` |
| 无 live agent | 记 `voice_no_agent`，提示打开一个会话 |
| 识别为空 | 忽略，不记事件 |
| 声纹分数低 | 拒绝，记分数；不泄露阈值细节 |

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 声纹误接受 | 先只做「拒绝陌生人」不做授权；阈值偏严；P3 用真模型 |
| 噪声/远场 | 登记时质量检查；VAD 能量门限可调；提示靠近麦克风 |
| 常开麦克风隐私 | 默认关；页面可见状态；关闭页面即停；不落盘 |
| 唤醒词误触发 | 先文本级 + 需完整唤醒词；P3 再考虑端上模型 |
| 宠物回复被再次拾音 | 回复期间暂停采集；后续 TTS 加回声消除 |
| 与 dsh-pet 麦克风冲突 | 两路独立；同一时间只允许一个录音源（UI 提示） |
| 宿主接口变动 | 只用公开服务；启动时探测，不可用则整块禁用并告警 |

## 8. 工作量与顺序

| 阶段 | 内容 | 估时 |
|---|---|---|
| P0 | spike + 接口确认 | 0.5–1 天 |
| P1 | 按住说话 + 声纹登记 + 设置页 | 2–3 天 |
| P2 | 常听 + VAD + 唤醒词 | 2–3 天 |
| P3 | 真声纹模型 + 质量与体验 | 3–5 天 |

总计约 8–12 个工作日；每阶段独立可交付、可回退（开关关闭即回到现状）。

## 9. 需要你拍板

1. **唤醒词**：默认「小鲸鱼」可以吗？还是换一个更不容易误触发的？
2. **默认识别策略**：未登记声纹时，允许任何人用，还是直接拒绝直到登记？
3. **常听默认值**：默认关闭、每次打开设置页手动开启，是否可以？
4. **识别文本留存**：`voice-events.jsonl` 里要不要存转写文本？（建议存，方便排障；可一键清空）
5. **先做到哪**：只做 P1（按住说话 + 声纹），还是直接连 P2（常听 + 唤醒词）一起？
