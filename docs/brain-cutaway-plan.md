# 3D 脑图剖面计划书（深部核团可见）

版本：v0.2（2026-11-19）
状态：已实现（采用 x-ray 透视核团，放弃平面剖切）
关联：`docs/mindmap-3d-plan.md`（v0.7 canvas 3D 网格）、`client.js`（BRAIN_REGIONS / buildBrain3D / drawBrain3D）

## 1. 问题

- 现在的 3D 图只在网格表面按方向着色；而八类情绪对应的多数结构在深部：
  杏仁核（颞叶内侧深部）、岛叶、前扣带、伏隔核、蓝斑、脑干。
- 只靠表面配色，用户会以为「生气」贴在大脑表面；选中标签又落在深部锚点，看起来像浮在脑内。
- 用户已确认要「剖面/半透明脑壳，露出深部核团位置」（m01437 选方案 3）。

## 2. 目标

1. 保留表面颜色占比（情绪像水填满脑壳）。
2. 剖开前上区域，露出内部，能看到 8 个深部核团的位置。
3. 核团颜色 = 情绪色，大小 ≈ 该情绪占比；可点击，点后看这类情绪的对话。
4. 仍然可拖拽/缩放，剖面在视图空间固定（始终朝观众），转动时核团随模型转。

## 3. 几何与渲染

- 剖面：壳面（`!face.deep`）中，视图空间法线满足 `n2z > 0.30 && n2y > -0.10` 的面不画，
  形成朝上前方的开口；开口内的壳背面压暗到 0.55 倍，作为内壁。
- 核团：在 `BRAIN_REGIONS` 锚点位置放小球体（latN 10 / lonN 16），半径
  `0.07R + 0.07R*sqrt(share)`（约 12–24px），三轴略扁（y×0.82），颜色固定为该情绪色，
  `deep: true`，加入同一面列表按深度排序。
- 光照：核团比表面略亮（自发光 0.12），选中时亮度 ×1.2 并加白描边。
- 标签：选中情绪时在核团位置写「名字 百分比」；占比 <5% 的情绪仍保留定位圆点。
- 性能：核团约 8×160 面，壳 ~10k 面，仍在一次绘制内。

## 4. 交互

- 点击核团或壳面都能选中对应情绪；点击空白取消。
- 图例、占比、详情卡沿用；提示文案说明「剖面露出的是深部核团，表面颜色仍表示占比」。

## 5. 里程碑

- M1：剖面开口 + 内壁压暗。
- M2：核团小球体 + 按占比定大小。
- M3：核团点击、选中标签、提示文案。
- M4：预览验收 + 真实宿主验证 + 文档/测试/提交。

## 6. 验收

- A34：3D 图能明显看到内部开口，开口内可见彩色核团。
- A35：杏仁核（生气）位于颞叶内侧深部，剖开后可见，不再只在表面。
- A36：核团大小随占比变化（疲惫最大、担心最小）。
- A37：点击核团选中对应情绪，详情卡列出该类对话。
- A38：拖拽旋转时剖面保持朝向观众，核团随脑转动，不出现黑块/漏底。
- A39：2D 视图与现有功能不受影响。

## 7. 风险

| 风险 | 处理 |
| --- | --- |
| 剖面开口太大，脑形认不出 | 先 30% 开口，预览后再调阈值 |
| 内壁颜色发黑、像空洞 | 内壁压暗而非纯黑，保留情绪色 |
| 核团被壳面挡住 | 统一深度排序 + 剖面开口；必要时核团最后画并加深度提示 |
| 点击误中 | 核团面优先于壳面命中 |

## 9. 实现记录（v0.18.0，2026-11-19）

- 平面剖切（§3 的原方案）实测会出现锯齿状开口、内部大片平坦网格面，像被咬掉一块；
  半透明壳叠加又出现网格纹，观感差。遂改为 **x-ray 透视核团**：
  - 壳面保持不透明、不剖切，表面占比不变。
  - 8 个核团小球（latN 10 / lonN 16，半径 0.115R，y×0.82）仍参与深度排序；
    壳画完后按 0.72 alpha 再叠一遍核团面，形成「透出来」的效果。
  - 核团大小按占比 `min(1.15, 0.58 + 0.5*sqrt(share))` 缩放，占比小的也保留可见。
- 点击优先级：先命中核团（deep），再命中表面；点核团看该类情绪对话。
- 限制：核团是「透视标记」而非真实剖面，视觉上仍浮在脑内；如果以后要真实剖面，
  需要按网格切平面并生成截面多边形（成本更高）。
