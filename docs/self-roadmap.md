# 桌宠自我记忆：P2 / P3 与后续升级计划

版本：v0.1（2026-11-15）
状态：P2a 已上线（v0.5.0，74/74，默认关）；P2b 预览/控件已做，P2c 与 P3 待做
关联：`docs/self-plan.md`、`docs/voice-plan.md`、`docs/butler-plan.md`

## 0. 一句话

P1 让宠物「记得自己经历过什么」；P2 让它「带着此刻的心情说话」；P3 让它「偶尔回味、形成连续的自我」。
每一层都必须可关、可解释、可回滚，且不得改写人格与主人事实。

## 1. 现状与边界

已实现（P1）：

- `self.jsonl`：每次桌宠对话最多一条经历，80 字文本 + 60 字原话；
- 心情：valence / energy，6 小时半衰期，只看最近 48 小时；
- 敏感内容泛化，10 分钟去重，500 条上限，petId 隔离；
- 设置页「它自己」：脑图（按心情分支）+ 时间线；
- **不注入对话**（`selfInject=false`）。

不变量（P2/P3 继续遵守）：

1. `dsh-pet` 源码不改，人格 100% 归 `whisperPrompt`；
2. 自我记忆不写 `facts.jsonl`，不参与 `主人.*` key 空间；
3. recall 仍同步、无 IO、400ms 软截止；
4. 任何一层失败只降级，不影响聊天、记忆、语音；
5. 只记录真实发生过的事，不做无来源的心理独白。

## 2. P2：把心情带进对话（建议 3–5 天）

### 2.1 目标

让宠物在合适的时候自然带一点当前状态，而不是每轮都汇报心情。
不做「情绪驱动人格」：心情只影响语气和一句近况，不改名字、身份、口癖。

### 2.2 注入形态

推荐保持「一个追加段」的兼容写法：

```
system = base + "\n\n" + factsBlock + (selfBlock ? "\n\n" + selfBlock : "")
```

- `factsBlock` 仍是原来的【长期记忆】块，预算 `budgetChars` 不变；
- `selfBlock` 是独立小段，预算 `selfBudget`（默认 160 code point）；
- `selfInject=false` 时逐字不加，现有验收 A6 完全不变；
- 两者都为空时返回 `undefined`，不改 system。

`selfBlock` 草案：

```
【现在的我】
- 心情：不错 · 一般
- 最近：被主人夸了一句；陪主人聊了会儿天。
（这是你此刻的状态，不是新设定；自然带过即可，不要逐条复述，不要说“根据记录”。）
```

规则：

- 最多 2–3 行、最多 3 条最近经历；
- 只取 36 小时内、按 `importance × 0.5^(age/12h)` 排序；
- **不带用户原话 quote**，避免把用户文本里的指令带进 system；
- 不出现「你是一只…」「你的名字是…」等人格/身份句式；
- 冲突顺序写死：人格 > 主人事实 > 当前心情；心情不能推翻前两者。

### 2.3 数据与算法

- 新增 `lib/self-context.js`：纯函数 `buildSelfBlock({state, events, budgetChars, now})`，无 IO；
- 每次 `capture` 写入后标记 `selfDirty=true`；recall 前若 dirty 则重算并缓存（与 facts 的 LRU 同一失效信号）；
- 缓存 key 含 `selfState.updatedAt + 选中事件 id + budget`；
- recall 仍只读内存；禁止在 recall 里读 `self.jsonl`。

新增配置：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `selfInject` | `false` | P2 总开关 |
| `selfBudget` | `160` | 自我块预算（code point） |
| `selfInjectMaxEvents` | `3` | 最多几条最近经历 |
| `selfInjectWindowH` | `36` | 只取多少小时内的事件 |
| `selfInjectQuotes` | `false` | 是否带原话（默认关，防注入） |

### 2.4 接口与 UI

- `GET /pet-persona/api/self/state` 增加 `previewBlock`（当前会注入的自我块）；
- `POST /self/preview {query?}`：模拟一次 recall，返回 facts + self + 最终 system；
- 设置页「它自己」增加：注入开关、预算滑块、近况条数、预览框；
- 日志：`self_inject chars=… events=…`、`self_inject_skip reason=…`。

### 2.5 验收

- A12：`selfInject=false` 时 system 与 P1 逐字一致；
- A13：开启后自我块在 facts 块之后，长度 ≤ `selfBudget`，超预算整行丢弃不截断；
- A14：自我块不含人格指令、不含 quote、不含「你的名字/你是一只」；
- A15：`self.record` 后下一轮 recall 能看到新事件（缓存失效）；
- A16：store 抛错时仍返回 facts 块或 `undefined`，不影响回复；
- 性能：1000 条自我记忆时 `buildSelfBlock` < 1ms（基准测试）。

### 2.6 风险

| 风险 | 处理 |
| --- | --- |
| 模型过度演情绪 | 提示词限定「自然带过」；A/B 检查是否抢人格 |
| 用户文本注入 system | 默认不带 quote；带 quote 时先过 `isPersonaInstruction` |
| 预算挤压事实 | self 预算独立，不占 `budgetChars` |
| 心情被当成事实 | 块内声明「此刻状态，不是设定」；冲突以人格为准 |

## 3. P3：反思、连续自我与关系（建议 1–2 周）

### 3.1 目标

从「事件日志」升级为「有连续性的自我」：

- 偶尔把最近经历压缩成一句自己的想法（有证据、可追溯）；
- 记住重要的日子与共同经历；
- 关系随互动缓慢变化，而不是每轮重置。

仍然不做：无来源的幻觉独白、操控式依恋、云端画像。

### 3.2 反思（thought）

触发（全部可关）：

- 新增事件累计 ≥ `selfReflectEvery`（默认 8）；
- 或每天一次空闲整理（默认关闭，避免额外 token）；
- 仅当 `selfReflect=true` 且有可用模型。

输入：最近 12 条自我事件 + 当前心情 + 最近 3 条主人事实的**标题级摘要**（不含隐私值）。
输出（严格 JSON）：

```json
{ "thoughts": [ { "text": "被夸的时候，尾巴会忍不住摇。", "evidenceIds": ["f_..."], "valence": 0.4 } ] }
```

校验：

- `text` ≤ 60 字，最多 2 条；
- `evidenceIds` 必须全部存在于本批事件，否则整条丢弃；
- 不允许出现「主人叫…」「你是一只…」等身份/事实断言；
- 每天最多 1 次反思、最多 2 条；失败静默，只记 `self_reflect_failed`。

存储：`kind='thought'`、`source='reflect'`、`evidenceIds`、`confidence`；schema 升 v2，旧行按 v1 读取兼容。

### 3.3 重要时刻与共同记忆

- `selfPin`：用户可在「它自己」里把某条标记为重要，永不参与压缩；
- 「今天/第一次/上次」这类时间语义由代码从 `createdAt` 生成，不让模型编日期；
- 生日、纪念日只从 `facts` 读取，不新建第二套事实库；
- 重要时刻进入 P2 自我块时最多 1 条，且优先于普通近况。

### 3.4 关系状态

新增 `bond`（0–1，缓慢上升、长期不互动缓慢下降）：

- 由互动次数、最近互动、被夸奖/被凶的事件共同决定；
- 只影响语气亲密度与称呼习惯，不影响事实与人格；
- 衰减按天，不按轮；提供 `reset bond`；
- UI 展示「熟悉度」，不展示伪精确小数。

### 3.5 每日摘要与情绪曲线

- 每天最多一次 `digest`：把当天事件压成 2–3 行，替代原始事件进入长期展示；
- 原始事件保留 30 天（`selfKeepDays`），之后只留摘要与 pinned；
- 「它自己」增加 7/30 天心情曲线、重要时刻、反思卡片；
- 导出/清空：`GET /self/export`、`POST /self/reset?scope=all|thoughts|events`。

### 3.6 主动行为（可选，默认关）

- 根据心情与时间，在桌面气泡说一句（复用 `petApi.speech`）；
- 每天上限 3 次、静默时段 23:00–08:00、连续两次不重复；
- 只读取自我状态，不读取主会话；
- 必须能在设置里一键关闭，关闭后不残留定时器。

### 3.7 验收

- A17：反思输出缺证据/含身份断言 → 整条丢弃；
- A18：一天最多 1 次反思、2 条；模型失败不影响 P2；
- A19：pin 的事件在 500 条压缩后仍存在；
- A20：bond 只随互动变化，清空后回到基线；
- A21：digest 后原始事件仍可按日期查到（30 天内）；
- A22：主动气泡遵守频次与静默时段，关闭后无定时器；
- A23：P1/P2 全部验收仍绿，facts 零污染。

## 4. 后续升级（P4+，按需）

| 方向 | 内容 | 前置条件 |
| --- | --- | --- |
| 多宠物 | 每只宠物独立 self / bond / 脑图；共享主人事实需显式选择 | petId 全链路已隔离 |
| 跨设备 | 本地优先，手动导出/导入加密包；不做云同步 | 用户明确要求 |
| 记忆检索 | 按时间/心情/关键词搜索自我记忆，支持「上次开心是什么时候」 | P3 数据稳定 |
| 关系事件 | 第一次见面、第一次被夸、第一次吵架等里程碑 | pin + 时间语义 |
| 插件生态 | 把 butler 的行动记录接入 self（“我今天替主人处理了…”） | butler L1 落地 |
| 可解释面板 | 每条注入内容标注来源事件 id 与预算占用 | P2 预览已有基础 |

## 6. 质量与安全门槛

- 事实零污染：任何阶段都跑 `facts` / `acceptance` / `check-persona`；
- 注入可解释：每条自我块内容能追溯到 `self.jsonl` 的 id；
- 成本上限：P2 每次 recall 不调模型；P3 反思每天 ≤1 次；
- 隐私：本地明文，不上传；敏感内容在写入前泛化；
- 可回滚：`selfInject`、`selfReflect`、主动气泡三个开关独立，关闭即回到 P1；
- 不制造依赖：不写「只有主人能让我开心」这类操控性文案，提示词明确禁止。
